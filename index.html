Help & Instructions

Workflow Modes ▼
Originals Only: Creates MoGRT clips with proportional timing and 0.7-second pauses.
Transliteration Workflow: Matches transliteration text with perfect timing inheritance.
Subtitle Workflow: Creates caption tracks with proportional timing distribution.
Key Features ▼
Proportional Timing: Word-count-based duration for natural pacing.
0.7-Second Pauses: Automatic breathing room between subtitle blocks.
Timing Inheritance: Transliteration perfectly mirrors original timing.
Dynamic Duration: Longer lines get more screen time automatically.
File Requirements ▼
• MoGRT file (.mogrt): Your motion graphics template.
• Script file (.txt): One subtitle line per row.
• Save as UTF-16 LE encoding for best compatibility.

How to save as UTF-16 LE:
1. Open in Notepad → File → Save As
2. Select Unicode (UTF-16 LE) in Encoding dropdown
3. Click Save
Reading Speed Control ▼
Reading Speed Slider (0-15):
• Range: 0 (slowest) to 15 (fastest)
• 0: Very slow reading speed (120 WPM equivalent)
• 15: Super fast reading speed (360 WPM equivalent)
• Recommended: 3-4 for most content (180-240 WPM)

How it works: The reading speed slider controls the timing calculations for subtitle placement. Higher values create faster-paced subtitles, while lower values create slower, more comfortable reading speeds. The script maps the slider value to words per minute for precise timing calculations.
Settings & Controls ▼
Word Spacing: Use slider or arrow buttons (0-15, 1.0 = normal).
Reading Speed: Use slider or arrow buttons (0-15, 4 = recommended).
Video Track: Which track to place clips on (1 = bottom layer).
MoGRT Name: Name for timeline clips (default: ColorTransition).
Timing Mode: Choose Automated or Manual with button interface.
Quick Start Steps ▼
1. Choose workflow mode from dropdown
2. Select files using blue "Choose File" buttons
3. Adjust word spacing with slider or arrows
4. Choose timing mode (Automated/Manual)
5. Enter times if manual (HH:MM:SS format)
6. Click Run Workflow or Create Subtitles
7. Check event panel for results
Pro Tips ▼
• Proportional timing creates natural subtitle pacing
• 0.7-second pauses ensure smooth transitions
• Word spacing affects visual word separation
• Consistent line breaks improve results
