# Subtitle Tool for Adobe Premiere

A lightweight CEP extension to streamline subtitle workflows in Adobe Premiere Pro. This plugin helps creators generate, edit, and manage subtitles directly within Premiere, reducing context-switching and speeding up post-production.

## Features
- **In-panel subtitle generation**: Generate subtitle lines from selected clips or markers without leaving Premiere.
- **Timing and alignment controls**: Nudge, snap, and auto-align subtitle timings to clip boundaries and markers.
- **Export and import support**: Export to SRT and import existing subtitle files to continue editing.
