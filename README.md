# Subtitle Tool for Adobe Premiere

A lightweight CEP extension to streamline subtitle workflows in Adobe Premiere Pro. This plugin helps creators generate, edit, and manage subtitles directly within Premiere, speeding up post-production.

## Features
- **Subtitle Insertion**: Generate subtitle lines from the script without leaving Premiere.
- **Subtitles with color transition**: Seperated into 2 different features, one is for normal text and other is for transliterations.
